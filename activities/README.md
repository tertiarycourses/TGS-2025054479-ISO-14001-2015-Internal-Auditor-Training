## How these are used

- Learners receive the **learner brief** (`.pdf` / `.docx`) in class.
- Trainers use the **`-trainer.docx`** pack, which adds the model answer, the answer guidance per question and the debrief notes.
- The same content appears in Section 5 of the Learner Guide, generated from the same source module, so the two can never diverge.
